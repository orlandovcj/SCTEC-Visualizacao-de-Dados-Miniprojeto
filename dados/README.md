## Dados do miniprojeto

Esta pasta contém os arquivos `.csv` referentes aos anos de 2020, 2021, 2022, 2023, 2024, 2025 e 2026 obtidos diretamente do portal de dados abertos. 

Os dados estão disponíveis publicamente no Banco de Preços em Saúde (BPF) mantido pelo Ministério da Saúde em: [https://dadosabertos.saude.gov.br/dataset/bps](https://dadosabertos.saude.gov.br/dataset/bps).

Por limitações de tamanho de upload de arquivos no GitHub, mantivemos os arquivos foram compactados em formato .ZIP.
